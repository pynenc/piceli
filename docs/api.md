# API reference

The Python API, generated from the docstrings: every module of the
`piceli` package with its classes, functions and constants.

**[Open the API reference](apidocs/index.rst)**

Start with the modules you import in a composition or an app:
[piceli.infra](apidocs/piceli/piceli.infra.md) (clusters, controllers,
build hosts), [piceli.envs](apidocs/piceli/piceli.envs.md) (environments)
and [piceli.testing](apidocs/piceli/piceli.testing.md) (a fake cluster for
tests). Each object links to its source on GitHub.
